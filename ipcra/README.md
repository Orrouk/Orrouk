# IPCRA — couche d'exécution GitHub

Ce répertoire contient les **missions, agents, règles d'exécution, schémas et tests** du système IPCRA.

## Séparation d'autorité

- **GitHub** : missions canoniques, agents, procédures exécutables, schémas, tests, changelog.
- **Google Drive** : sources, corpus, manuscrits, recherches, exports, images, EPUB, livrables, produits finis et journaux humains.
- **Obsidian** : navigation, MOC, relations, fiches atomiques, familles de versions et décisions éditoriales sur les contenus conservés dans Drive.

Une mission GitHub peut lire ou modifier Drive selon son contrat, mais **ne doit pas recopier les corpus dans GitHub**.

## Règle de migration

Les missions actives ou réutilisables deviennent canoniques ici. Les anciennes missions ponctuelles, résultats et rapports restent dans Drive/Archive sauf raison précise de les versionner.

Pendant la transition :
1. ne supprimer aucune définition historique dans Drive;
2. copier la définition canonique dans GitHub avec sa provenance;
3. vérifier les références Drive et la gouvernance;
4. remplacer ensuite, si utile, la copie Drive par une fiche miroir courte pointant vers GitHub.
