# AGENTS.md — Gouvernance IPCRA dans GitHub

## Portée
Ce fichier gouverne `ipcra/`.

## Autorité
GitHub est l'autorité pour :
- missions canoniques;
- agents;
- procédures réutilisables;
- schémas;
- tests;
- changelog d'exécution.

Google Drive demeure l'autorité pour :
- sources originales;
- corpus et voûtes;
- manuscrits;
- exports et médias;
- recherches;
- produits, livrables et publications;
- journaux humains de migration et d'audit.

Obsidian demeure la couche de connaissance et de navigation sur les contenus Drive.

## Interdictions
Un agent travaillant ici ne doit pas :
- importer un corpus ou un manuscrit complet dans GitHub;
- déplacer, renommer ou supprimer une source Drive sans mission explicite;
- créer un second canon documentaire;
- considérer une mission ancienne comme active sans preuve;
- casser les protections d'Epub ou des voûtes gouvernées;
- modifier un canon éditorial pour simplifier la migration technique.

## Migration des missions
Lorsqu'une mission est migrée de Drive vers GitHub :
1. conserver son identifiant stable;
2. inscrire sa provenance Drive;
3. préserver ses dépendances, entrées, sorties et protections;
4. indiquer son statut : ACTIF, PILOTE, EPROUVE, DEPRECIE ou ARCHIVE;
5. ne supprimer la définition Drive qu'après validation explicite; par défaut, conserver une fiche miroir ou l'original historique;
6. consigner toute divergence entre version Drive et version GitHub.

## Règle d'arbitrage
Si une mission touche à l'identité d'une œuvre, à un canon, à une variante, à une voûte gouvernée ou à une suppression potentielle, arrêter et marquer **ARBITRAGE_REQUIS** sauf si une autorité existante tranche déjà explicitement.

## Fin de mission
Tout agent doit produire :
- changements effectués;
- fichiers GitHub créés ou modifiés;
- références Drive touchées;
- divergences détectées;
- arbitrages requis;
- prochaine action.
